## 4. 标题钩子公式(强制的三条规则)

### ✅ 有效结构

```
① 数字 + 认知颠覆
   "同样是家办的深度,为什么成本差了三个数量级"

② 对比 + 重新定义
   "产品货架的访问权,不等于理解的访问权"
   "分散在五处,和看得见,是两件事"

③ 类比 + 挑衅
   "没有体检报告的治疗,都是碰运气"
```

### ❌ 禁用结构

```
× 市场判断类:"下周 A 股怎么看"
× 产品导向类:"三只基金配置建议"
× 自嗨类:"我们的技术如何领先"
× 蹭热点类:"AI 概念股全线飘红"
```

### 禁用词

| 禁用 | 原因 |
|------|------|
| 推荐 / 建议买入 | 投顾红线 |
| 稳赚 / 保本 / 必涨 | 刑法 + 证券法红线 |
| 涨 / 跌 预测 | 投资建议 |
| 收益率 | 暗示收益 |

## 5. 单篇文章结构(固定模板)

```
① 标题(钩子型)
② 导语(140-200 字,直击一个真实场景)
③ 现象描述 → 为什么会这样
④ 认知反转(这是核心,必须有一个"其实不是这样")
⑤ 机制解释(为什么,不是应该)
⑥ AstorAI 的位置(轻提,不推销)
⑦ 行动引导 → 免费诊断
⑧ 相关文章 × 3
⑨ 免责声明
```

**字数**:1600–2400 字(中文)
**排版**:段落不超过 4 行,每 300 字至少一个 pull-quote / callout / 表格

## 9. 写作原则(给写手看的)

### ✅ 要做的

- **讲结构,不讲产品** —— 让读者自己发现"我需要这个"
- **承认不知道** —— 哪些需要持牌机构,直说
- **用具体场景** —— "一个五百万账户分散在三处的家庭"比"高净值人群"有效 10 倍
- **给可带走的东西** —— 每篇至少一个能记住的判断

### ❌ 不要做的

- **不要自夸** —— "行业领先""业界首创"零效果,甚至减分
- **不要暗示收益** —— 一次都没有
- **不要提具体产品** —— 基金、券商、保险的名字都不出现
- **不要用 AI 味表达** —— 少用"赋能""抓手""闭环"

### 语气基准

- 参照"一个资深顾问在跟你聊天",不是"公司在发通稿"
- 句子短一点,观点明确一点
- **敢说难听的** —— "这个问题你答不上来,是因为你没想过"
